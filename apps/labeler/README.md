# MarmoLabel: סימון קריאות בטלפון

אפליקציית אנדרואיד לסימון קריאות על הקטעים של דקה, כמו ב‑Audacity, בלי חיבור לרשת אחרי ההורדה.

- **קובץ ההתקנה:** `apps/labeler/build/marmolabel.apk` (44 KB). נבנה מחדש עם `apps/labeler/build.sh`.
- **הוראות הסימון המלאות:** `docs/LABELING.md`, בסעיף "Labelling on the phone".

## התקנה

1. מעבירים את `marmolabel.apk` לטלפון בכל דרך: וואטסאפ לעצמך, דרייב, מייל או כבל.
2. פותחים אותו בטלפון ומתקינים. אנדרואיד יבקש לאשר התקנה מהאפליקציה שממנה פתחת את הקובץ.
3. במחשב, כשהטלפון באותה רשת וויפי, מריצים:
   ```bash
   python tools/labels/phone_server.py
   ```
   השרת מדפיס כתובת וקוד בן 6 ספרות. אם macOS שואל אם לאפשר ל‑Python לקבל חיבורים נכנסים, מאשרים.
4. באפליקציה מזינים את הכתובת ואת הקוד ולוחצים "⬇ הורד הקלטות".

> רשת הוויפי בקמפוס חוסמת לפעמים תקשורת בין מכשירים. אם הטלפון לא מצליח להתחבר, ההורדה תעבוד בבית, כשהמחשב והטלפון באותה רשת.

## מה יש באפליקציה

**הקלטות.** השרת מגיש רק קטעים שעוד לא סומנו: 8 הקטעים שנשארו ב‑test (ts_08 עד ts_15), ו‑40 קטעים חדשים ב‑train2. כל קטע ב‑train2 נחתך סביב קריאה שהגלאי מצא, כך שאף אחד מהם לא ריק. קטעים שכבר לא מוגשים נמחקים מהטלפון כדי לפנות מקום; סימונים לעולם לא נמחקים.

אחרי ההורדה האפליקציה עובדת בלי חיבור. בכל פתיחה בוויפי, כשהשרת רץ, היא מושכת לבד קטעים חדשים ואת הסימונים שנמצאים במחשב.

**רשימת הקטעים.** ליד כל קטע מופיע המצב שלו: לא הורד, "מהמחשב" (סומן ב‑Audacity), בעבודה, גמור או נשלח.

**מסך הקטע:**
- **ניווט:** פס עליון מציג את כל הקטע; נגיעה בו קופצת לאותו מקום. מתחתיו ספקטרוגרמה: צביטה בשתי אצבעות מגדילה, וגרירה בשתי אצבעות גוללת.
- **סימון:** גוררים אצבע אחת כדי לבחור קטע זמן, ולוחצים "c" או "?". הקשה על סימון בוחרת אותו, ואז מתקנים את הגבולות בגרירת הידיות העגולות.
- **השמעה:** "▶ נגן" משמיע את הבחירה, או את החלון שעל המסך כשאין בחירה.
- **ביטול:** "↶ בטל" מבטל את השינוי האחרון, כולל סימון חדש. אין כפתור מחיקה נפרד.
- **קטע בלי קריאות:** מסמנים "הקטע גמור" בלי לסמן כלום, והקטע נשמר אוטומטית כ"אין קריאות" (כמו `none` ב‑Audacity).

**שמירה.** כל שינוי נשמר מיד. קטע יוצא מהטלפון רק אחרי שמסמנים "הקטע גמור", ואז הוא נשמר בשתי דרכים:
- **אוטומטית** ל‑`Download/MarmoLabel/<קבוצה>/<קטע>.txt` בטלפון, כדי להעביר אותו ידנית למחשב.
- **בכפתור "⬆ שלח למחשב"**, ישר לתיקיית הסימונים של הקבוצה בפרויקט, כשהשרת רץ. אם כבר יש שם קובץ שונה, הישן נשמר קודם ב‑`labels/.bak/`.

הקבצים בפורמט של Audacity, כך שהייבוא הקיים (`import_audacity.py`) קורא אותם בלי שינוי.
